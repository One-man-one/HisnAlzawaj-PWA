# حصن الزواج — تطبيق الويب (PWA)

بابٌ ثانٍ للمشروع لا يمرّ بتيليجرام: من وصل ولا يملك التطبيق **لا
يُفقد عند الزرّ**.

هذا المستودع **الواجهة وحدها** — صفحاتٌ ساكنة تُثبَّت على الهاتف وتعمل
بلا اتصال. والبوت وقاعدة البيانات في مستودعٍ آخر.

⚠️ **ولا تُنسخ هنا.** الخطة تحكم العمل في المستودعين معاً (والوسيط

## الملفّات

```
index.html              الصفحة الوحيدة اليوم — هيكل التطبيق
offline.html            ما يُعرض حين تنقطع الشبكة وتُطلب صفحةٌ غير مخزَّنة
app.css                 الأنماط، ومعها النمط الداكن
app.js                  تسجيل عامل الخدمة، وحالة الاتصال، وزرّ التثبيت
sw.js                   عامل الخدمة — ⚠️ فيه أخطر سطرٍ هنا (رقم الإصدار)
manifest.webmanifest    تعريف التطبيق: الاسم والأيقونات وسلوك التثبيت
brand/logo_mark.png     الشعار الرسمي — مصدر الأيقونات كلّها
icons/                  مولَّدة منه — لا تُحرَّر بيدٍ
tools/make_icons.py     مولّدها (يحتاج Pillow)
```

## التشغيل محلياً

```bash
python3 -m http.server 8000
```

ثم `http://localhost:8000`.

⚠️ **ولا تفتح `index.html` بنقرةٍ مزدوجة.** بروتوكول `file://` **يعطّل
عامل الخدمة إطلاقاً** — فترى الصفحة تعمل وتظنّ التطبيق سليماً، بينما
كلّ ما في هذا المستودع من عملٍ بلا اتصال معطَّلٌ عندك ولا شيء يقول ذلك.
و`localhost` استثناءٌ مسموح كما لو كان HTTPS.

### إعادة توليد الأيقونات

```bash
pip install Pillow
python3 tools/make_icons.py
```

بعد أي تغييرٍ في `brand/logo_mark.png` أو في المولّد نفسه.

⚠️ **والشعار منسوخٌ من مستودع البوت** (`assets/logo_mark.png`)،
فتحديثُه هناك لا يصل هنا من نفسه.

## النشر

استضافةُ ملفّاتٍ ساكنة — GitHub Pages تكفي، كما يُنشر موقع البوت
وعجلةُ تاريخ الميلاد اليوم.

⚠️ **وHTTPS شرطٌ لا اختيار:** عامل الخدمة لا يعمل على `http://`، وبدونه
لا تثبيتَ ولا عملَ بلا اتصال — أي أن المشروع كلّه يصير صفحةً عادية.

⚠️ **والمسار الفرعي ليس تفصيلاً:** Pages يخدم من
`…github.io/hisnalzawaj-pwa/`، ونطاقُ عامل الخدمة هناك ذلك المسار لا
جذر النطاق. ولذلك **كل مسارٍ في هذا المستودع نسبيّ** — الشرح في
`CLAUDE.md`.
